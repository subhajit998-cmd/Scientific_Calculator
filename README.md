# 🧮 Scientific Calculator

A modern, responsive **Scientific Calculator** built with **HTML, CSS, and JavaScript**. It provides both basic and advanced mathematical operations through a clean and user-friendly interface.

🔗 **Live Demo: "https://subhajit998-cmd.github.io/Scientific_Calculator/"

---

## ✨ Features

* ➕ Addition, subtraction, multiplication, and division
* 🔢 Decimal number calculations
* 📐 Trigonometric functions

  * `sin`
  * `cos`
  * `tan`
* 🧮 Scientific functions

  * Square
  * Square root
  * Power
  * Logarithm
  * Natural logarithm
  * Factorial
* 📊 **DEG / RAD** angle modes
* 🧹 Clear and delete functions
* 🔄 Real-time calculation display
* 📱 Responsive design
* 🎨 Modern calculator interface
* ⚡ Fast and lightweight
* 🌐 Runs directly in a web browser
* 🚫 No backend or database required

## 🚀 How to Run

### Method 1 — Run Locally

1. Clone the repository:

git clone https://github.com/subhajit998-cmd/Scientific-Calculator.git


2. Open the project folder:

cd Scientific-Calculator


3. Open `index.html` in your web browser.

That's it! 🎉

---

### Method 2 — Use VS Code

1. Download or clone the repository.
2. Open the project in **Visual Studio Code**.
3. Open `index.html`.
4. Use **Live Server** to launch the project.
